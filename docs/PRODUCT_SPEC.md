## 1. 제품 비전 및 경험

**[확정]** 세로 화면 2D 픽셀아트 중세 판타지 싱글플레이 모바일 전술 전략 게임. 플레이어가 작은 영구 마을에서 건물을 배치하고 연구·영구 성장시킨 뒤, 스테이지형 수성/공성 전투에서 유닛·시설 배치, 전투 강화, 진화, 스킬, 경로 제어를 운용한다. 전투는 여러 웨이브와 재정비로 진행되며, 메인 캠페인과 필수 진행을 막지 않는 선택 스테이지가 존재한다.

**게임의 차별점**
- 전투 이전의 마을 성장과 전투 내 경제·유닛 개체별 강화/진화가 연결된다.
- 유닛은 기본적으로 AI가 이동·교전·자동 스킬을 수행하지만, 플레이어는 선택 유닛의 위치·수동 스킬·강화·진화 및 건설/경로 개입을 결정한다.
- 수성은 아군 핵심 거점을 보호하고, 공성은 웨이브별 적군 및 시설을 제거하며 마지막 웨이브의 적 핵심 시설을 파괴한다.
- Godot Inspector 및 소수의 전용 제작 패널로 새로운 콘텐츠를 지속 공급할 수 있다.

## 3. 전체 게임 범위와 MVP 경계

### 3.1 MVP — 반드시 제공

**[확정]** 전투 방식은 수성·공성(각 스테이지는 단일 모드), 메인 6개 + 선택 2개 = 총 8스테이지. 총 웨이브 수의 **제작 목표는 26개**이며 개별 스테이지/웨이브 수는 테스트로 증감 가능. 수성 4개/공성 4개는 현재 **[설계초안]** 배분이다. 플레이 중 재정비, 적 초기 배치 + 순차 증원, AI, 유닛 5종·진화 6형태, 적 6종, 전투 시설 4종, 플레이어 설치 가능 불가침 장애물, 마을 성장 건물 4종, 스토리/연구 해금, 저장/복원, 편집 도구, 자동 검증 및 비공개 배포가 범위에 포함된다.

### 3.2 전체 게임 방향 — MVP의 기능·수량과 구분

**[후속]** 수성 보스전/공성 보스전, 추가 진영·유닛·진화·시설, 확장된 스토리 분기와 던전, PvP, iOS 출시, 클라우드 저장·백업, 고급 편집 패널/운영 콘텐츠 등. **MVP 5개 유닛·4개 시설·8개 스테이지가 전체 게임의 상한이 아니다.** 후속 모드 구현 가능성을 데이터/시스템 경계에서 고려하되 MVP에 보스전이나 PvP를 끼워 넣지 않는다.

## 4. 플레이어 흐름

1. 앱 최초 실행 → **메인 화면** → **마을**. 본부는 미리 배치, 검사·궁수 해금, 시작 영구 재화 보유.
2. 플레이어가 초기 재화로 **훈련소 직접 건설**. 첫 훈련소 비용은 반드시 충당 가능하도록 제공.
3. 캠페인 화면에서 해금된 메인/선택 스테이지 진입 → 스테이지 시작 자원으로 초기 아군 배치 → 첫 웨이브 시작.
4. 웨이브 전투 중 AI 행동·전투 강화·진화·수동 스킬·유닛 이동·시설 신규 건설·장애물 신규 설치를 조작.
5. 웨이브 완료 보상 이후 다음 웨이브 병력·시설이 **비활성화된 채 미리 배치**되며 재정비(기본 30초, 데이터별 조정, 조기 시작 가능/추가 보상 없음).
6. 재정비 동안 생존 유닛 위치 재배치/추가 소환, 유닛 강화·진화, 시설 신규 건설·기존 시설 이동·수리, 장애물 설치·이동·회수. 생존 유닛은 HP 완전 회복/상태이상 제거, 사망 유닛은 미복구. 시설 HP는 유지, 유료 수리.
7. 타이머 종료 또는 조기 시작 → 체크포인트 **저장 성공 후** 웨이브 활성화. 실패 시 전투 시작 차단, 재시도 또는 메인 이동.
8. 승리·패배·명시적 포기 → 보상 일관성 있게 정산 → 결과 화면 → 마을. 정상/비정상 앱 종료는 **포기와 다르며**, 마지막 체크포인트에서 짧은 카운트다운 후 자동 복원.

## 5. 캠페인·스테이지

### 5.1 잠금·해금 [확정]

- 메인 스테이지는 이전 필수 메인 스테이지 클리어를 통해 순차 진행하며, 선택 스테이지의 클리어 여부는 메인 진행을 막지 않는다.
- **MVP 기본 유닛 5종 모두 스토리 즉시 해금**. 처음 검사·궁수, 이후 창병 → 지원병 → 마법사 순서. 전체 게임의 '선택 유닛은 연구 해금' 정책과 구분.
- **해금 시점 [확정]**: 시작—검사·궁수/본부/훈련소 건설, M1 완료—창병 및 기본 영구 강화, M2 완료—공방과 S1, M3 완료—지원병과 마법 연구소, M4 완료—마법사와 S2, M5 완료—고급 시설·진화 연구 기회 확대, M6 완료—MVP 메인 캠페인 완료. 기본 전투 시설과 경로 장애물은 M2에서도 사용 가능해야 하며 공방에서의 추가 연구는 M2 이후.
- 모든 진화 형태는 마을 연구로 영구 해금한다. M4에서 진화를 경험할 수 있도록 검사/궁수의 진화 연구를 M3 이전에 사용할 수 있어야 한다. 진화는 필수 스테이지 승리에 없어도 되도록 설계하는 것을 우선 권장한다.
- 한번 해금된 스테이지는 반복 플레이·재도전 가능. 반복 보상 존재.

| ID | 모드 | 웨이브안 | 맵/주요 전술 | 적 웨이브 구성 초안 |
|---|---|---:|---|---|
| M1 국경 초소 | 수성 | 2 | 넓은 단일 진입로; 검사·궁수의 기본 배치 | W1 고블린 전사, W2 전사+궁수 |
| M2 갈림길 방어전 | 수성 | 3 | 두 갈래 진입, 화살탑·방어벽·불가침 장애물 | W1 양방향 전사, W2 전사+궁수 증원, W3 오크+고블린 |
| M3 버려진 요새 | 공성 | 3 | 고정 맵/우회로/방어벽 돌파 | W1 고블린 수비대, W2 오크+화살탑, W3 오크+적 핵심 |
| M4 숲의 방어선 | 수성 | 4 | 좁은 통로/다중 출현, 전투 강화·진화 시도 | W1 고블린, W2 돌격병, W3 궁수+돌격병, W4 혼합+증원 |
| M5 마법사의 성채 | 공성 | 4 | 원거리 공격/지원 시설, 마법사·지원병 조합 | W1 고블린+탑, W2 오크+지원 시설, W3 마법사+오크, W4 마법사+지원병+핵심 |
| M6 최후의 성문 | 공성 | 4 | 다중 방어선·핵심 구역, 종합 전술 | W1 혼합, W2 돌격+방어벽, W3 마법사/지원병/시설, W4 종합 수비대+핵심 |
| S1 협곡 방어전 | 수성 | 3 | 좁은 길/건설 공간 제약, 경로 전술 | W1 고블린, W2 궁수+전사, W3 오크+돌격 증원 |
| S2 비밀 보급로 | 공성 | 3 | 우회로/지원시설/선택 진격 | W1 전사+궁수/탑, W2 오크+지원병, W3 혼합+핵심 |

### 5.3 승리·패배 [확정]

- **수성:** 아군 핵심 시설을 보호하고 최종 웨이브의 필수 적·증원 제거 시 승리. 아군 핵심 시설 파괴 시 즉시 패배. 아군 유닛 수 0만으로 수성 패배하지 않는다는 해석은 **[설계초안]**이며 명세 승인 필요.
- **공성 일반 웨이브:** 살아 있는 필수 적 0 + 예정된 필수 증원 0일 때 완료. 새 웨이브에는 그 웨이브의 적 시설 배치 정보만 적용; 이전 웨이브 적 시설은 제거.
- **공성 최종 웨이브:** 적 핵심 시설 등장; 이를 파괴하면 적 병력이 남아도 즉시 승리.
- **공성 전투 중 아군 생존 필드 유닛 0이면 즉시 패배**, 잔여 소환 자원·시설 생존 여부와 무관. 시작 배치 단계에는 최소 1기 배치 후 활성화하도록 검증하는 것은 **[설계초안]**.
- 스테이지별 특수 종료 조건은 데이터 확장을 고려하되 MVP 필수 모드 규칙을 변경하지 않는다.

## 6. 웨이브·증원·재정비

**[확정]** 웨이브는 처음부터 모든 적이 활성화되는 방식이 아니다. `InitialEnemies / 초기 배치 적`과 `Reinforcements / 증원 적`을 분리한다. 초기 적과 적 시설은 재정비 시작 시 미리 배치되나 움직이거나 공격/피격·공격 대상이 되지 않는 **비활성** 상태이며, 전투 시작 후 활성화된다. 순차 증원은 지정 시점·출현 지점·그룹/수량을 따름. 초기 적 및 적 시설 중복 출현·시설의 웨이브 간 잔존은 금지.

- 재정비 기본 30초, 스테이지/웨이브 데이터로 변경. 타이머 종료 시 자동 시작, 플레이어 조기 시작 가능, 조기 시작 추가 보상 없음.
- 적 증원 출현 위치 충돌 → 대체 타일/대체 출현 지점 확인 → 정해진 제한 시간 재시도 → 실패 시 **보상 없이 안전 종료**, **현재 유효 체크포인트 보존**. 구체 제한 시간 및 재시도 간격은 **[미결정·설정값]**.
- 증원이 예정되면 현재 생존 적이 0이어도 웨이브를 완료하지 않는다. 완료/패배/승리 판정은 상태 전이를 한 번만 실행해야 함.
- 시설/장애물·유닛 배치, 적 출현과 경로 검증의 순서를 일관되게 유지.

## 7. 아군 유닛·성장·진화

### 7.1 MVP 기본 5종 [확정]

| 기본 유닛 | 역할 고정 | 개별 전투 강화 목록 **[확정]** |
|---|---|---|
| 검사 / Swordsman | 근접 공격 기준·연속 공격 | 연속 베기, 출혈, 회전 베기, 돌진 |
| 궁수 / Archer | 원거리·긴 사거리 | 관통, 다중 화살, 빙결 화살, 폭발 화살 |
| 창병 / Spearman | 높은 생존력·전선 제어 | 밀쳐내기, 반격, 도발, 방패 방어 |
| 지원병 / Support | 약한 기본 공격 + 부상 아군 치유 우선 AI | 광역 치유, 보호막, 공격 지원, 상태이상 해제 |
| 마법사 / Mage | 높은 공격 효과·광역 마법, 낮은 내구 | 연쇄 마법, 범위 확대, 화상, 마력 폭발 |

**[확정]** 유닛별 강화 4항목, **각 항목 최대 3단계**. 유닛 스킬은 자동·수동 혼합, 스킬 제작 시 동작방식 고정(플레이어 토글 불가). 자동 스킬은 AI가 시전; 수동 스킬은 선택 유닛 주변에서 발동. 전투 강화는 기본 공격/기존 스킬 효과를 변경하는 지속 효과일 수 있고, 별도 발동 스킬과 혼동하지 않는다.

### 7.2 진화 형태 6종 [확정된 범위 / 세부 예시는 설계초안]

| 원본 | 진화 후보 | 조건·스킬의 현재 제안 |
|---|---|---|
| 창병 | 수호 창병 | 총 강화 5 + 방패 방어 2 → 수호 오라(자동) |
| 검사 | 기사 | 총 강화 5 + 돌진 2 → 영웅 돌격(수동) |
| 궁수 | 얼음궁수 | 총 강화 5 + 빙결 화살 3 → 서리 폭풍(수동) |
| 궁수 | 폭파레인저 | 총 강화 4 + 폭발 화살 2 + 다중 화살 2 → 폭발 화살비(수동) |
| 마법사 | 대마법사 | 총 강화 5 + 연쇄 마법 2 → 비전 폭풍(수동) |
| 지원병 | 사제 | 총 강화 4 + 광역 치유 2 → 성역(수동) |

- **[확정]** 진화는 기존 개체의 ID/위치/강화 단계를 유지하는 상태 변화이며 새 상위 유닛 직접 소환은 불가. 진화 후에도 기존 강화 목록에서 계속 구매 가능. 진화 시 특수 스킬 추가, 모든 진화 형태는 마을 연구 해금 필요, 전투 중 강화 조건과 별도 전투 자원 소비 필요.
- **[확정]** 요구 강화의 **단계 수치**, 전투 비용, 스킬 효과량은 플레이 테스트로 조정한다. 위 조건값/스킬명은 초기 제안, 확정값 아님. 궁수 진화 둘 중 한 경로만 선택하고 같은 단계 재진화 불가 정책은 **[설계초안]**.
- **[확정]** 기본 유닛 역시 자동·수동 스킬 혼합, 진화 시 별도 특수 스킬 추가. 기본 유닛별 자동 1+수동 1, 진화 스킬별 자동/수동 예시는 **[설계초안]**.

### 7.3 전투 중 생존 규칙 [확정]

웨이브 종료 시 **생존 아군** 위치, 개체별 강화·진화, 생존 상태 유지, **HP 완전 회복 + 상태이상 모두 해제**. 사망 유닛은 부활하지 않음. 다음 재정비에 생존 유닛 위치 재배치 가능. 전투 중 유닛 직접 이동은 선택 후 목적지 터치 → 걷기 이동; 텔레포트 불가, 이동 명령 중 공격 중단, 스킬 실행 중 수동 이동 불가. 공성 유닛은 수동 이동 종료 후 기본 AI 자동 진격으로 복귀.

## 8. 전투 스킬·상태이상·피해 계산

### 8.1 스킬/쿨타임 [확정]

- 자동 스킬/수동 스킬은 콘텐츠 제작 시 고정, 자동은 AI 조건 판단, 수동은 유닛 주변 컨트롤; 플레이어 독립 스킬은 하단 공통 조작부.
- 스킬별 독립 쿨타임. 성공적으로 발동될 때만 자원 소비/쿨타임 시작. 취소/실패 시 무소모.
- 재정비·일시정지 시 쿨타임 정지, 다음 웨이브에 남은 시간 그대로 이월. 진화 후 추가된 스킬은 즉시 사용 가능. 2배속은 전투 시뮬레이션 시간에 연동.
- **[확정]** 출혈/화상: 각각 최대 3중첩, 각 중첩의 지속시간 개별 관리; 빙결/기절: 중첩 불가, 재적용 시 시간 갱신; 동일 효과 그룹의 버프는 가장 강한 효과 적용, 동일 그룹 보호막은 가장 큰 수치 적용; 서로 다른 상태이상은 동시 적용 가능.

### 8.2 피해 공식 [확정 구조 / K 수치 테스트 조정]

```
유효방어력 = max(0, 방어력 감소·관통을 반영한 방어력)
방어 계산 피해 = 방어 전 피해 × K / (K + 유효방어력)
```

K의 테스트 초기 예시는 100으로, 확정 값이 아니다. 계산 순서는 **기본 공격·스킬/강화 효과 → 피해 증감 → 고정·비율 관통 → 방어력 반영 → 보호막 차감 → HP 차감 → 상태이상 부여**. 광역 공격은 대상별로 각각 계산. 상태이상 부여에는 스킬 적중/저항 조건을 검토할 수 있으며 세부 저항 식은 **[미결정]**. 지속 피해가 방어력·보호막과 상호작용하는 세부 규칙은 스킬 데이터에 명확히 정의할 것.

### 8.3 지원병 치유 [확정]

지원병은 약한 기본 공격이 가능하되 **회복 가능한 아군 중 현재 HP 비율이 가장 낮은 유효 대상**에 치유 우선 AI 적용. 초과 치유 없음, 사망 유닛 치유/부활 불가. 대상이 없거나 치유할 수 없으면 일반 AI 공격/대기. 치유는 보호막 스킬과 별도 기능으로 취급한다.

## 9. 적 유닛 6종·AI

### 9.1 적 역할 [확정]

| 적 | 역할 / 기본 AI 방향 |
|---|---|
| 고블린 전사 | 빠른 근접 공격, 가까운 적을 추적 |
| 고블린 궁수 | 원거리 공격, 사거리 유지·회피 |
| 오크 전사 | 높은 HP·전선 유지, 근접 교전·필요 시 방어벽 파괴 |
| 오크 돌격병 | 진격·시설 돌파, 핵심 목표/방어벽 접근 |
| 적 마법사 | 광역 공격·상태이상, 밀집 대상 선호 |
| 적 지원병 | 회복·강화 우선, 약한 공격 가능 |

**[확정]** 공통 FSM(상태 및 실행) + Utility AI(상황 점수) + A* 이동 경로 구조. 적 역할 고정, 유닛별 기본 AI 프로필에 웨이브별 가중치 보정 허용, 각 웨이브의 증원 일정 별도 설정. AI 고려 요소 후보: HealthRatio/체력 비율, TargetDistance/대상 거리, AttackReady/공격 준비, EnemyCount/주변 적 수, ThreatLevel/위협도, ObjectivePriority/목표 중요도, TravelCost/이동 비용, BreakCost/장애물 돌파 비용, AllyHealthRatio/아군 체력 비율, SkillAvailable/스킬 사용 가능, GroupSupport/아군 지원, StatusEffect/상태이상. 이 12개는 **후보 집합**이지 확정된 유일·폐쇄형 enum이 아니다.

- 행동 가능 여부 먼저 판단 후 가중치 평가. 이동 우회 비용과 파괴 비용을 비교. 유닛/시설 타입마다 공격 가능 대상, 경로 통과 유형, 스킬이 다를 수 있음.
- 주기적 AI 재평가와 중요 사건(타깃 사망, 경로 변경, 막힘 등)의 즉시 재평가를 혼합. 구체 주기/가중치/캐시 정책은 프로파일 및 성능 테스트로 조정.
- 공성 최종 목표 가중치는 높되 무조건 지정 목표로 이동하는 것이 아니라 현재 위협·접근성·교전 가능성을 반영.

## 10. 시설·장애물·배치

### 10.1 MVP 시설 4종 [확정]

| 시설 | 기능(세부 강화는 제안) |
|---|---|
| 화살탑 | 단일 대상 원거리 지속 공격; 관통·다중 사격 등 |
| 마법탑 | 광역/상태이상 공격; 빙결·연쇄 공격 등 |
| 지원 초소 | 치유·보호막·공격 지원 등 |
| 방어벽 | 파괴 가능한 경로 제어·피해 흡수 |

**[확정]** 일반 전투 시설은 종류별 HP/파괴 가능 여부/차단 특성 데이터로 동작. 전투 중 신규 시설 건설 허용, 기존 시설 이동 불가. 재정비 중 기존 시설 무료 이동·신규 건설·유료 수리. 살아남은 시설은 웨이브 사이 HP가 유지되고 자동 회복하지 않음. 재건설 시 신규 비용, 파괴된 시설의 전투 강화 소멸은 **[설계초안]**. 수리 가능 시점을 재정비로 제한하는 정책은 **[설계초안]** (비용을 통한 수리 자체는 확정). 공성 적 시설은 웨이브 종료 시 제거, 다음 웨이브 정의대로 생성.

### 10.2 불가침 장애물 [확정]

- **플레이어도 설치 가능한 `TerrainObject / 지형 오브젝트`**, 4종 전투 시설과 별도 분류. 파괴·수리 불가.
- 최초 설치 시 전투 자원 소비; 회수한 **동일 개체** 재설치는 무료, 회수로 재화 환급 없음.
- 재정비: 설치·이동·회수 허용. 전투 중: **신규 설치만 허용**, 기존 배치의 이동/회수 불가. 회수해 보관 중인 개체의 재설치는 신규 설치 명령으로 취급 가능.
- 스테이지별 **최대 보유 수**와 **최대 동시 배치 수**를 각각 정의. 배치된 장애물은 양쪽 수에 포함, 보관된 장애물은 보유 수에만 포함.
- 어떠한 설치·이동도 필수 경로를 전부 차단하면 안 됨. 실패 배치는 취소·재화 미차감. 이동 유형 및 출현 지점별 검증, 현재 점유 타일 배치 금지 등 세부 절차는 **[설계초안]**. 파괴 가능한 방어벽은 적이 파괴하는 경로로 인정할 수 있으나, 파괴 불가능한 장애물은 우회 경로 필수.

## 11. 마을·연구·영구 성장

### 11.1 건물 [확정]

MVP 성장 건물은 **본부·훈련소·마법 연구소·공방 4종**(초기 6종 제안을 통합하는 최종 정책). 성장 건물 종류별 최대 1개, 건물 레벨 없음, 건설·연구·강화는 실시간 대기 없이 즉시 완료. 마을은 작은 타일맵의 영구 공간; 건물 선택/배치/이동/보관/재배치, **이동·보관·재배치 모두 무료**. 보관 중 새 연구·강화는 불가, 이미 취득한 영구 효과는 유지. 성장 건물 철거/환급·성장 재분배 불가. 장식/일부 보조 건물은 중복 가능·환급 없는 철거 가능.

| 건물 | 역할 |
|---|---|
| 본부 | 캠페인·마을 관리, 건물 해금 확인 |
| 훈련소 | 검사·궁수·창병 영구 강화와 진화 연구 |
| 마법 연구소 | 지원병·마법사 영구 강화와 진화 연구 |
| 공방 | 전투 시설 연구·영구 강화, 공통 전술 일부 |

시작 본부 자동 배치/훈련소 직접 건설, 초기 비용 보장. 시설/연구 메뉴는 해당 건물 선택으로 진입. 정확한 건물 타일 크기/디자인/초기 재화액은 **[미결정]**.

### 11.2 연구/해금 [확정]

- 영구 성장 재화는 **공통 1종**, 일부 특별 해금 토큰/조건은 통화가 아닌 선행 조건으로 취급.
- MVP 기본 5종은 스토리 즉시 해금; 연구는 **모든 진화 형태**, 추가 전투 시설 및 능력치 영구 강화에 사용. 전체 게임에서는 선택 유닛 연구 해금 체계 확장 가능.
- 연구 해금은 조건+비용 충족 시 즉시 효과 적용, 취소/환급/초기화 없음.
- 유닛별 영구 성장은 기본 능력치(공격력/공격속도/사거리/HP/방어/이동 등)를 변경, 전투 중 유닛 개체별 강화는 공격 행동/전술 효과를 변경한다. 두 계층의 변경 대상/지속 범위를 혼동 금지.

## 12. 두 재화의 수급·소비

### 12.1 전투 전용 자원 [확정]

- 스테이지별 시작 자원 설정 + 최초 기본 배치가 가능하도록 최소 자원 보장.
- 적 처치 **확정 즉시** 지급(중복 처치 방지), 웨이브 완료 보상 **1회**, 미사용 전투 자원 다음 웨이브에 **전액 이월**. 조기 시작 추가 보상 없음.
- 소환·시설 건설·유닛 전투 강화·진화·시설 수리·불가침 장애물 최초 설치에 지출.
- 소환/시설/진화의 상대 비용 관계와 상위 강화 단계 비용 증가만 **확정**; 실제 수치·단위는 테스트 조정. 스테이지 종료 시 미사용 자원 소멸.
- 체크포인트에 잔여 자원·개체 상태·보상 지급 여부 저장. 웨이브 중 종료 시 해당 웨이브 중간 획득/소비는 롤백.

### 12.2 영구 성장 재화 [확정]

- 스테이지 최초 클리어 보너스와 반복 클리어 기본 보상을 **분리**. 패배·명시적 포기 시 **완료 웨이브 수만** 반영한 부분 보상; 진행 중 웨이브 진행률은 반영하지 않는다.
- 건설·연구·영구 강화에 소비, 환급/재분배 없음.
- 보상/비용의 **상대적 우열**과 초반 성장 목표만 확정: **첫 1~2회 클리어 내 영구 강화 체험**, **첫 3~5회 클리어 내 진화 연구 가능**. 숫자·보상 지수는 **[설계초안]**.
- 메인 진행의 필수 건물·유닛이 선택 스테이지 보상을 요구하지 않도록 구성. 재화 부족 영구 진행 차단 방지.

## 13. HUD·조작·시간 제어

- **[확정]** 전장 전체 고정 카메라, 세로형. 상단 HUD에 웨이브·자원·핵심 HP·타이머·증원 등 표기 **[설계초안]**; 화면 경계 터치 안전영역 필요.
- **[확정]** 유닛 주변에 스킬/강화/진화 상황별 버튼, 시설 주변에 강화/수리/이동 등 상황별 버튼. 하단 공통 영역은 소환·건설·플레이어 스킬·일시정지 등 전역 조작. 타일 터치는 선택/이동/배치/스킬 대상 지정의 입력 상태에 따라 처리.
- **[확정]** 해당 스테이지 **최초 클리어 전 1배속**, 클리어 후 재플레이 시 2배속 허용. 일시정지 중 상태/정보 확인만 가능, 실행/예약 명령 불가. 전투·증원·재정비·쿨타임 시계 정지 **[설계초안]**.
- 겹친 개체 선택 후보, 버튼 클리핑 보정, 취소 시 자원 미소모 등 세부 UX는 **[설계초안]**.

## 14. 저장·복원·예외

### 14.1 체크포인트 [확정]

- **웨이브 시작 직전**, 플레이어의 재정비 변경을 모두 반영한 일관된 스냅샷을 저장한 후 전투 활성화. 정상 종료·강제 종료 후 앱 재실행 시 해당 스냅샷으로 자동 복원하고 짧은 카운트다운 뒤 자동 재개.
- 앱 백그라운드 복귀는 살아 있는 프로세스의 일시정지/재개로 처리; 강제 종료가 아닌 경우 불필요한 체크포인트 재생성 안 함.
- 스냅샷: 스테이지/웨이브 ID, 콘텐츠/스키마/저장 버전, 전투 자원, 아군 유닛의 ID/위치/HP/강화/진화/쿨타임, 아군 시설의 위치/HP/강화, 장애물 보유/배치 상태, 해당 웨이브 적 초기/증원 정의 또는 재현 가능한 참조, 보상 지급 플래그 등. 실제 세부 필드/직렬화 형식은 Codex 설계.
- 저장 실패 시 웨이브 시작 차단 및 **저장 재시도 / 메인 이동 선택 제공**. 이전 유효 체크포인트는 덮어쓰기 실패로 손상시키지 않음. 메인 이동 시 미저장 재정비 변경 유실 가능성을 안내.
- 승리·패배·포기 **확정 시 보상과 진행 기록을 중복 없이 정산하고 체크포인트 정리**. 포기: 명시 확인 → 완료 웨이브 수 기반 부분 보상 → 결과 화면 → 마을. 단순 앱 종료는 포기가 아님.
- 콘텐츠 업데이트로 체크포인트 복원이 **실제로 불가**할 경우 해당 체크포인트만 무효화하고 **메인 화면**으로 이동. **영구 성장·캠페인 진행 초기화 금지**.
- 증원 출현 시간 제한 실패는 저장 실패나 포기가 아닌 **안전 종료**: 체크포인트 유지, 별도 보상 없음. 다음 실행 시 같은 체크포인트 복원 가능.

### 14.2 저장·버전 불변 규칙 [확정]

`INV-01~13` 전체를 적용. 안정 ID(변경 시 명시적 매핑 허용), 모든 참조 유효, 연구/해금 순환 금지, 진화 조건 달성 가능, 웨이브/경로 유효, 검증 Error 시 빌드 차단, 콘텐츠 버전/스키마 버전/저장 형식 버전 구분, 버전 변경만으로 삭제 금지, 영구 성장과 전투 체크포인트 독립 호환성, 마이그레이션 실패 시 원본 보존, 복원 불가능한 체크포인트만 무효화, 영구 성장 임의 초기화 금지. 상세 규칙은 `REQUIREMENTS.md` 및 `DECISIONS.md`를 참조.

## 15. 콘텐츠 제작 도구 [확정된 범위]

- Godot Inspector 기반 일반 데이터 편집 + **전용 패널 3개**: **(1) 스테이지·웨이브 통합 (2) 진화 (3) 강화**. 별도 스킬 전용 패널은 MVP에 포함하지 않는다.
- 전체 스테이지 실행 및 **선택 웨이브 직접 실행** 지원. 특정 웨이브 테스트의 초기 조건은 실제 플레이와 분리된 테스트 프로필에서 지정(구체 프로필 필드 **[설계초안]**).
- 테스트 데이터/실제 플레이 데이터 **완전 격리**.
- 유효성 검증은 편집기·CI 공통 계약을 사용하며 **Error는 빌드 차단/오류 목록 출력**, **Warning은 표시만**.
- 앱 업데이트에 콘텐츠 포함, GitHub Actions 검증·빌드 후 Google Play 비공개 테스트 배포.

## 16. 상세 밸런스 초기안 — 미승인 값의 취급

**[설계초안]** 이전 기획에서 예시로 제시된 검사 HP 120/공격 20/공격 간격 1초/사거리 1타일, 궁수 HP 80/공격 15/1.2초/5타일, 창병 HP 180/공격 15/1.4초/2타일, 지원병 HP 90/공격 5/1.5초/3타일, 마법사 HP 75/공격 25/1.8초/4타일과 화살탑 HP 200/마법탑 150/지원초소 180/방어벽 350 등은 **숫자 확정이 아니다**. 유닛/시설 비용, 적 보상 지수, 증원 간격(10~20초), 진화/연구 비용 또한 마찬가지. 확정된 것은 **역할의 상대적 우열·비용 증가 구조·성장 체험 목표**이다. 시범 데이터에는 명시적으로 `BALANCE_SEED / 시험 초기값`을 표시하고 조정 가능하도록 설계.

## 17. Codex 구현 원칙·마일스톤

Codex는 내부 클래스·파일 경로·Resource 타입/필드명을 자유롭게 설계할 수 있다. **그러나 외부 게임 규칙, 데이터의 의미, 검증 계약, 저장 안정성, MVP 범위는 임의 변경할 수 없다.** 작업 순서/인수 기준은 `REQUIREMENTS.md`에 정의.

1. 프로젝트 골격·데이터 계약·검증·CI
2. 최소 수성 수직 슬라이스(배치, AI, 웨이브, 승패, 저장)
3. 공성·경로 파괴/우회·장애물 검증
4. 유닛 5종, 적 6종, 시설 4종, 전투 강화·스킬·진화
5. 마을·영구 성장·캠페인 해금·경제
6. 미리보기·전용 패널 3종·콘텐츠 8스테이지
7. 자동/실기기 테스트, 최적화, Google Play 비공개 테스트 빌드
