## B. 확인된 최신 명시 결정 — DEC-367~650대

## E. 사용자 승인 없이 고정하면 안 되는 설계초안·미결정

- 8개 스테이지의 이름·맵 구조·모드별 세부 배분·각 웨이브 적 수량과 증원 시간은 **초안**이며 26웨이브는 목표치이다.
- 유닛/시설/적의 구체 HP·공격력·방어 계수 K·이동/공격 속도·사거리 및 비용은 **초기 밸런스 숫자**일 뿐이다.
- 진화 이름의 구체 표기·강화 요구 단계 수치·각 스킬명/개수/쿨타임/효과량·특수 스킬 자동·수동 목록은 일부 예시 상태다.
- 수성 아군 0명 상황, 증원 제한 시간/안전 종료 재개 UX, 시설 수리 가능 시점, 시설 강화 단계 상한, 장애물 회수/재설치의 입력 세부 UX는 최신 결정으로 완전히 확정되지 않았다.
- `AIProfile` 12개 고려 요소는 기존 후보, 강제 최종 enum/스키마가 아니다. 가중치와 각종 테스트 시간은 데이터로 조정한다.
- 참조 데이터 계약의 의미는 확정됐으나 Godot 실제 Resource/씬/클래스 파일 구조는 Codex 자율 설계이다.
